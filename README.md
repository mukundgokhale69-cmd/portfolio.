# portfolio
Mukund Gokhale - Personal Portfolio
A simple, responsive personal portfolio website built using HTML5
and CSS3. The website introduces the developer, highlights education
and skills, showcases projects, and provides contact information.
Features
- Personal introduction and profile photo
- Education section
- Skills list
- Project showcase
- Contact information
- Black, dark grey, and white colour theme
- Hover effects and responsive layout
Technologies Used
- HTML5
- CSS3
Project Structure
Portfolio/
├── index.html
├── style.css
└── images/
    └── photo.jpg
The images/photo.jpg file is optional if the profile image URL in
index.html is used instead.

How to Run
1. Download or clone this project.
2. Open the project folder in Visual Studio Code or another code
   editor.
3. Make sure index.html and style.css are in the same folder.
4. Open index.html in a web browser.
5. Alternatively, use the Live Server extension in Visual Studio Code.
Customization
- Update the name and introduction in index.html.
- Add or edit education details, skills, and projects.
- Update the email, phone number, location, and GitHub link in the
  contact section.
- Change colours, spacing, and layout in style.css.
- Replace the profile image URL with your own image.
